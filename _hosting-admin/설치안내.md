# 홈페이지 관리자 — 서버에 올리는 방법

이 폴더(`admin`)는 **웹호스팅 서버에서 동작하는 관리자**입니다.
담당자 PC를 켜 둘 필요가 없고, 아이디·비밀번호만 알면 어느 PC에서든 들어와서
내용을 고치고 저장할 수 있습니다.

---

## 1. 준비물

| 항목 | 내용 |
|---|---|
| 호스팅 | **PHP 5.6 이상** 이 되는 웹호스팅 (라성에너지 기존 호스팅으로 충분합니다) |
| 접속 정보 | FTP 주소 · 아이디 · 비밀번호 |

> 참고 : 지금 ecopole.kr 은 **Apache + PHP 7.4** 에서 돌아가고 있습니다.
> 그 호스팅을 그대로 쓰면 추가 비용이 들지 않습니다.

---

## 2. 올리기

FTP 프로그램(파일질라 등)으로 접속해서, 홈페이지 폴더에 아래를 **통째로** 올립니다.

```
index.html  ·  about.html  ·  notice.html …  (홈페이지 전체)
assets/     (이미지 · CSS · JS)
post/       (공지 상세 페이지 — 없으면 자동으로 생깁니다)
admin/      ← 관리자
```

**올리지 않아도 되는 것** : `_admin`, `serve.ps1`, `_config.yml`, `.git`

### 폴더 권한

관리자가 파일을 고쳐야 하므로 아래 폴더에 **쓰기 권한(755 또는 707)** 이 필요합니다.
대부분의 호스팅은 기본 설정 그대로도 동작합니다. 저장할 때 권한 오류가 나면 이 부분을 확인하세요.

- 홈페이지 폴더 전체 (HTML 파일을 고쳐야 합니다)
- `admin/data`, `admin/backups`
- `assets/sub`, `assets/cases` (사진 교체)
- `files` (게시판 첨부, 없으면 자동 생성)

---

## 3. 첫 접속 — 관리자 계정 만들기

브라우저에서 아래 주소로 들어갑니다.

```
https://내홈페이지주소/admin/
```

계정이 하나도 없으면 **「관리자 계정 만들기」** 화면이 자동으로 뜹니다.
아이디 · 이름 · 비밀번호를 정하면 바로 관리자로 들어갑니다.

> 이 화면은 **처음 한 번만** 나옵니다. 계정을 만들고 나면 다시 열리지 않습니다.
> 그러니 **올리자마자 바로 계정을 만들어 두세요.** (그 사이 다른 사람이 만들면 안 되므로)

---

## 4. 다른 사람에게 열어주기

관리자 화면 → **접속 계정** → **계정 추가**

| 권한 | 할 수 있는 일 |
|---|---|
| **수정 가능** | 내용 수정 · 사진 교체 · 공지 등록 · 문의 관리 — 모든 기능 |
| **보기 전용** | 내용을 볼 수만 있고, 저장 · 되돌리기가 잠깁니다 |

만든 아이디와 비밀번호를 알려주면 그 사람도 어느 PC에서든 접속할 수 있습니다.
필요 없어지면 **삭제**를 눌러 그 계정만 막으면 됩니다.

---

## 5. 문의 폼 연결

관리자 화면 → **문의 접수** → **연결 켜기**

이걸 켜면 홈페이지 온라인문의 · A/S문의로 들어온 내용이
**24시간 자동으로** 관리자 화면에 쌓입니다.

---

## 6. 보안에 관해

- 비밀번호는 **암호화해서** 저장됩니다. 파일을 열어봐도 원래 비밀번호는 알 수 없습니다.
- 비밀번호를 5번 틀리면 5분 동안 잠깁니다.
- 계정 · 문의 내용 파일(`admin/data/`)은 주소로 직접 열어도 **내용이 보이지 않습니다.**
  (`.htaccess` 로 막고, 파일 자체도 `.php` 로 두어 이중으로 보호합니다)
- 접속 주소가 **https** 인지 확인하세요. http 면 비밀번호가 그대로 오갑니다.
  호스팅에서 무료 SSL(Let's Encrypt)을 켤 수 있습니다.

## 7. 검토용 주소(GitHub Pages)에 관해

지금 쓰는 <https://seyeong1403.github.io/rasung-energy/> 는 **정적 호스팅**이라
PHP가 동작하지 않습니다. 그래서 그곳에는 `admin` 폴더가 올라가지 않도록
`_config.yml` 에서 제외해 두었습니다.

검토용 주소에서는 문의 폼도 예전처럼 **「리디자인 시안」 안내**만 뜨고 실제로 전송되지 않습니다.

## 8. 자주 나오는 문제

**「파일을 저장하지 못했습니다」**
→ 폴더 쓰기 권한 문제입니다. 위 2번의 권한 안내를 확인하세요.

**사진을 올리면 「용량이 너무 크면…」 이라고 나옵니다**
→ 호스팅의 업로드 용량 제한(`post_max_size`)에 걸린 것입니다.
   사진을 2MB 이하로 줄여서 올리거나, 호스팅에 제한을 늘려 달라고 요청하세요.

**비밀번호를 잊었습니다**
→ FTP로 `admin/data/users.php` 를 지우면, 다음 접속 때 「관리자 계정 만들기」 화면이
   다시 나옵니다. 새로 정하면 됩니다. (기존 글·문의 내용은 그대로 남습니다)

**관리자 주소가 검색에 나올까요?**
→ 검색엔진 차단(`noindex`)이 걸려 있어 노출되지 않습니다.
